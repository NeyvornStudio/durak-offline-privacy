Политика конфиденциальности

Мобильная игра «Дурак Оффлайн»

Дата редакции: 10 ноября 2026 года

1. Общие положения

Настоящая Политика описывает обработку информации при использовании мобильной игры «Дурак Оффлайн» (далее — «Игра»), выпускаемой под брендом NEYVORN STUDIO. Игра предназначена для одиночной игры и не требует регистрации или создания учётной записи.

2. Локальные данные игры

Игра может сохранять на устройстве настройки, игровой прогресс и статистику партий. Эти данные необходимы для сохранения пользовательских предпочтений и работы игровых функций. По предусмотренной модели работы игры они не отправляются на сервер разработчика.

3. Данные, обрабатываемые рекламным сервисом

Игра предусматривает интеграцию Yandex Mobile Ads SDK. При наличии рекламного модуля и подключении к интернету рекламный провайдер может обрабатывать IP-адрес, рекламный идентификатор (если доступен), сведения об устройстве и операционной системе, технические события, а также данные о показах рекламы и взаимодействиях с объявлениями. Фактический объём обработки зависит от версии SDK, настроек устройства и согласий пользователя, если они требуются.

Обработка рекламных данных осуществляется рекламным провайдером согласно его документам, в том числе Политике конфиденциальности Яндекса.

4. Для чего используются данные

Локальные данные используются для работы игры. Данные рекламного провайдера могут использоваться для показа объявлений, измерения их эффективности, обеспечения безопасности и противодействия мошенничеству.

5. Работа без интернета

Основной игровой процесс доступен без подключения к интернету. Соединение может требоваться для загрузки рекламных объявлений; отсутствие интернета не должно препятствовать одиночной игре.

6. Передача данных

Разработчик не продаёт персональные данные пользователей. При работе рекламного SDK технические данные могут передаваться Яндексу и обрабатываться им на условиях применимых документов и законодательства. Данная Политика не означает, что все указанные категории данных собираются в каждой сессии.

7. Хранение и удаление

Локальные игровые данные обычно сохраняются до очистки данных Игры пользователем или удаления Игры (с учётом возможных механизмов резервного копирования операционной системы). Сроки хранения информации рекламным провайдером определяются его правилами и применимым законодательством. Пользователь может очистить локальные данные через настройки Android. По вопросам обработки данных рекламным провайдером следует также ознакомиться с его политикой.

8. Защита информации и права пользователей

Разработчик стремится минимизировать обработку данных. Пользователь может пользоваться предусмотренными устройством настройками конфиденциальности и рекламного идентификатора, а также обращаться по вопросам доступа, уточнения и удаления персональных данных в пределах, установленных законодательством.

9. Дети

Игра не предусматривает преднамеренного запроса личных данных у детей. При распространении игры среди несовершеннолетних необходимо соблюдать применимые возрастные требования и правила рекламных сервисов.

10. Обновления политики

При изменении функций игры, рекламных технологий или законодательства эта Политика может обновляться. Актуальная версия публикуется на этой странице с указанием даты редакции.

11. Контактная информация

Разработчик: NEYVORN STUDIO. Профиль разработчика на GitHub: github.com/NeyvornStudio.

Электронная почта для вопросов конфиденциальности и обработки данных: neyvorn.studio@internet.ru.

По вопросам обработки персональных данных можно обратиться по указанному адресу. Сведения о юридически ответственном лице уточняются перед публикацией приложения в магазине. Не размещайте персональные данные в публичных GitHub Issues.
